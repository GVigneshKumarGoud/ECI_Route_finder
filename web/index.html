⚙️ Algorithm & Data Structures

The core computer science concepts behind ECI Route Finder

🔵

Graph Theory

The city's road network is modelled as a weighted, undirected graph where intersections and landmarks are vertices and roads are edges. Each edge carries two weights — distance and travel time — enabling multi-criteria shortest-path searches.

Vertices (V) = 20 Hyderabad locations
Edges    (E) = 30 roads (bidirectional)
Type         = Undirected, Weighted
Weights      = distance_m, travel_time_min
📋

Adjacency List

An adjacency list stores only existing edges, using O(V + E) memory instead of O(V²) required by an adjacency matrix. For sparse graphs like road networks this is far more efficient.

typedef struct {
    int to_index;
    int distance_m;
    int travel_time_min;
} Neighbour;

Neighbour adj[20][10];
int neighbour_count[20];
⚡

Dijkstra's Algorithm

A greedy shortest-path algorithm that progressively relaxes edges, always selecting the unvisited vertex with the smallest tentative distance. It guarantees the optimal path when all edge weights are non-negative.

  1. Initialise dist[source] = 0, all others = ∞
  2. Mark all vertices unvisited
  3. Pick the unvisited vertex u with the smallest dist[u]
  4. For each neighbour v of u, relax the edge: if dist[u] + weight(u,v) < dist[v], update dist[v] and set parent[v] = u
  5. Mark u visited; repeat from step 3 until destination is visited
🧮

Complexity Analysis

Time complexity depends on the data structure used for selecting the minimum-distance vertex.

ImplementationTime Complexity
Simple array (this project)O(V²)
Min Heap / Priority QueueO((V+E) log V)
Nodes (V)20
Edges (E)30
💻

C Implementation

The core algorithm is implemented in pure C with no external libraries. The dijkstra() function accepts the graph, source, destination, and a mode flag to switch between distance and time optimisation.

void dijkstra(
    int adj[][MAX_NEIGHBOURS],
    int neighbour_count[],
    int num_locations,
    int source,
    int destination,
    int mode   // 0 = distance, 1 = time
);
🔄

Two Route Modes

The algorithm supports two optimisation criteria. The mode flag selects which edge weight to use during relaxation.

ModeEdge Weight UsedOptimises For
Distancedistance_mShortest total km
Timetravel_time_minFastest total minutes

The parent[] array reconstructs the full path from destination back to source after the algorithm completes.

🎯 Problem Statement

During emergencies in a large city like Hyderabad, every second counts. Ambulances and first responders need to reach incident sites via the fastest possible route — but choosing the optimal path across dozens of roads and intersections is non-trivial.

ECI Route Finder solves this by modelling Hyderabad's road network as a weighted graph and applying Dijkstra's algorithm to find the shortest (distance) or fastest (time) route between any two of the 20 mapped locations.

🚀 How to Compile

Build and run the C application with GCC:

cd "ECI_Route_Finder"

gcc ads_c/src/graph.c ads_c/src/dijkstra.c \
    -o eci_route_finder.exe

./eci_route_finder.exe

Then open web/index.html in a browser for the interactive dashboard.
